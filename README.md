# 三角洲行动装备随机抽取系统

一个带有用户登录和历史记录功能的三角洲行动装备随机抽取系统。
注意：如果抽取图片加载不出来，请访问这个网站https://www.dpcamp.cn/，访问后会跳出提示，点击高级，继续访问，给予授权，因为这个网站的证书过期了，需手动授权

## 功能特性

- ✅ 用户注册和登录
- ✅ 游客登录（临时使用，不保存到数据库）
- ✅ 随机抽取角色、主武器、地图、头盔、装甲
- ✅ 保存抽取历史记录
- ✅ 查看历史记录详情
- ✅ 删除历史记录
- ✅ 每个用户独立的历史记录
- ✅ 游客模式历史记录仅保存在当前会话

## 安装步骤

### 1. 安装 Node.js

确保你的电脑已安装 Node.js（建议 v14 或更高版本）

### 2. 安装依赖

在桌面目录打开命令行（PowerShell 或 CMD），运行：

```bash
npm install
```

### 3. 启动服务器

```bash
npm start
```

服务器将在 http://localhost:3000 启动

### 4. 访问网页

在浏览器中打开：
```
http://localhost:3000/三角洲随机装备页面.html
```

## 使用说明

### 注册账号

1. 首次使用需要注册账号
2. 输入用户名和密码（至少6位）
3. 点击"注册"按钮
4. 注册成功后切换到登录模式

### 登录

1. 输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后进入主界面

### 抽取装备

1. 点击"开始抽取"按钮，装备开始随机滚动
2. 再次点击"停止抽取"按钮，停止滚动并显示结果
3. 点击"保存记录"按钮，将当前抽取结果保存到历史记录

### 查看历史记录

1. 左侧面板显示所有历史记录的简略信息
2. 点击任意历史记录，弹窗显示详细信息（包括所有装备图片）
3. 在详情弹窗中可以删除该记录

### 退出登录

点击右上角的"退出登录"按钮

## 技术栈

- **前端**: Vue 3, HTML5, CSS3
- **后端**: Node.js, Express
- **数据库**: SQLite
- **认证**: JWT (JSON Web Token)
- **密码加密**: bcryptjs

## 文件说明

- `三角洲随机装备页面.html` - 前端页面
- `server.js` - 后端服务器
- `package.json` - 项目依赖配置
- `delta.db` - SQLite 数据库文件（首次运行自动创建）

## 注意事项

1. 首次运行会自动创建数据库文件
2. 用户密码经过加密存储，安全可靠
3. 登录状态会保存在浏览器本地，关闭浏览器后仍然保持登录
4. 历史记录按时间倒序排列，最新的在最上面

## 常见问题

**Q: 无法连接到服务器？**
A: 确保服务器已启动（运行 `npm start`），并且访问的是 http://localhost:3000

**Q: 注册时提示用户名已存在？**
A: 请更换一个新的用户名

**Q: 忘记密码怎么办？**
A: 目前没有找回密码功能，可以注册新账号，或者删除 `delta.db` 文件重新开始（会清空所有数据）

## 开发模式

如果需要修改代码并自动重启服务器，可以使用：

```bash
npm run dev
```

这需要先安装 nodemon（已包含在 devDependencies 中）
